# 에어 컨펌 도우미

에어 리스트 컨펌용 웹 도구입니다. 설치 없이 브라우저에서 바로 쓸 수 있습니다.

## 수요일 컨펌 / 금요일 컨펌
위쪽 탭으로 고릅니다. 두 리스트는 따로 기억되므로 서로 지워지지 않습니다.
- **수요일 컨펌**: 월요일에 에어 요청한 반장님 리스트 기준
- **금요일 컨펌**: 에어 리포트 기준

리스트는 복사해서 붙여넣거나, **📂 엑셀 파일 넣기**(또는 ① 칸에 파일을 끌어다 놓기)로 엑셀을 그대로 넣을 수 있습니다. 시트가 여러 개면 넣을 시트를 고릅니다. Maker 이름을 누르면 그 업체 행이 모두 선택되어 CONFIRM을 한 번에 넣을 수 있습니다.

## 미컨펌이란
**리스트에는 있는데 컨펌 내역에 없는 품목**입니다. 전체 리스트(반장님 리스트 등)와 컨펌 내역을 차례로 넣으면, 컨펌 내역에 없는 품목이 주황색으로 남습니다. CONFIRM 칸에 값이 있는 표는 컨펌 내역으로, 없는 표는 전체 리스트로 자동 구분하며, ① 칸의 선택 상자로 직접 정할 수도 있습니다. 미컨펌 행에 STOCK이나 CONFIRM을 직접 적으면 컨펌된 것으로 바뀝니다.

## 사용법
1. 메일이나 엑셀의 요청 리스트를 헤더까지 복사해서 ① 칸에 붙여넣고 **추가 / 합치기**를 누릅니다. 여러 리스트를 넣으면 하나로 합쳐집니다.
2. (선택) ② 칸에 이전에 보낸 리스트를 붙여넣으면 신규 품목은 `ADD`, 수량이 바뀐 품목은 `CHANGE Q'TY`가 자동으로 표시됩니다.
3. ③ 표에서 STOCK, CONFIRM, REMARK를 입력합니다. CONFIRM에 `11/17`을 넣으면 `17-Nov`로 바뀝니다.
4. ③ 표 위의 **📊 엑셀 다운로드 (F1,2 / F5)** 를 누르면 메일 표와 같은 색·글씨의 엑셀(시트 F1,2 / F5)이 내려받아집니다.
   미컨펌 품목(리스트에는 있는데 컨펌 내역에 없는 주황색 행)만 받으려면 **📊 미컨펌만 엑셀 다운로드**를 누릅니다.
5. ④ F1·F2, ⑤ F5 메일의 **메일 본문 복사**를 누르고 Outlook에 붙여넣습니다. 표는 FAC → Maker → Part Name 순으로 정렬됩니다.

입력한 데이터는 각자 브라우저에만 저장되고 서버로 전송되지 않습니다.
